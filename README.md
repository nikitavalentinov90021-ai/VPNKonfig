🚀 VLESS Configurator (ConfigName)

Универсальный конфигуратор vless-серверов с удобным графическим интерфейсом (GUI). Программа автоматизирует процесс полной очистки, категоризации и ребрендинга конфигураций для подписок, приводя теги в идеальный, читаемый вид.

---

✨ Основные возможности

* **Автоматическое распознавание типа сети:** Скрипт сканирует теги на ключевые слова и автоматически определяет подключение (**WiFi** или **LTE**).
* **Умная очистка имен:** Из названия удаляется весь технический "мусор", оставляя только чистое название страны и флаг.
* **Кастомный брендинг:** Возможность в один клик указать название своего бренда (например, `QuorVPN`), которое автоматически подставится во все конфигурации.
* **Поддержка флагов (Emoji):** Корректно извлекает и сохраняет эмодзи-флаги стран.
* **Обратное кодирование (URL Encode):** Все измененные теги кодируются обратно в URL-формат для 100% стабильной работы в любых клиентах (v2rayNG, Streisand, Nekobox и др.).
* **Удобный GUI:** Больше никакого терминала и ручного ввода путей — выбирайте файлы через стандартный проводник и следите за логами в реальном времени.

## 🛠️ Как запустить (Для разработчиков / Из исходного кода)

Если вы хотите запускать программу напрямую через Python:

### 1. Требования
У вас должен быть установлен Python версии **3.10 или выше**.

### 2. Установка зависимостей
Установите библиотеку для современного графического интерфейса:
```bash
pip install customtkinter

3. Запуск
Bash

python gui_app.py

📦 Как собрать в самостоятельный .exe файл

Чтобы использовать программу как обычное приложение Windows (без установленного Python):

    Установите упаковщик pyinstaller:
    Bash

    pip install pyinstaller

    Запустите сборку одной командой (если у вас есть файл иконки logo.ico):
    Bash

    pyinstaller --noconsole --onefile --clean --icon="logo.ico" gui_app.py

    Заберите готовый файл в появившейся папке dist/.

🚀 Инструкция для пользователей (Как пользоваться .exe)

    Запустите файл QuorVPN_Config.exe.

    В поле "Выберите файл с серверами" нажмите кнопку Обзор и выберите ваш текстовый файл со списками vless://.

    В поле "Название бренда" введите свой бренд (по умолчанию стоит QuorVPN).

    Нажмите кнопку "Запустить очистку".

    Программа обработает все строки. Новый, абсолютно чистый файл с суффиксом _renamed сохранится в той же папке, где лежал оригинал!

    ⚠️ Обратите внимание: При первом запуске Windows SmartScreen может выдать предупреждение, так как у собранного вручную .exe файла нет платной цифровой подписи. Нажмите "Подробнее" -> "Выполнить в любом случае". Это абсолютно безопасно.
